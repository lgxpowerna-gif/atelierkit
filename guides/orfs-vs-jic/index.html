ORFS vs JIC : lequel t'as en main

RéponseNez pointu, pas de caoutchouc : JIC. Face plate avec un O-ring dedans : ORFS. Même filet, des fois, mais pas le même siège.

Raccord ORFS vs JIC : les deux sont droits, les deux se mesurent sur le filet. Tu les mélanges si tu regardes juste le diamètre.

  • JIC 37° : le bout est pointu. L'étanchéité est sur le cône à 37°.
  • ORFS : le bout est plat. L'O-ring est dans une gorge, dans la face.

Exemple : 0.562 po, 18 filets. Ça peut être un mâle JIC -6 ou un ORFS -4. Sors pas la pièce avant d'avoir vu le bout.

Questions rapides

Le filet est pareil ?

Parfois. JIC -6 et ORFS -4 font tous les deux 9/16-18. C'est le bout qui n'est pas le même.

Ça visse ensemble ?

Non. Le siège pointu du JIC ne scelle pas sur la face plate de l'ORFS.
