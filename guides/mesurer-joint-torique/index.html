Comment mesurer un joint torique (ID, section, AS568)

RéponseSection d'abord, puis le trou. Dash 214 : ID 0.984 po, CS 0.139 po, OD 1.262 po.

Comment mesurer un joint torique : la dimension d'un joint torique, c'est trois chiffres. La section (CS), le trou (ID), le dehors (OD). OD = ID + 2 × CS.

Exemple AS568 déjà dans l'outil, le dash 214 : trou 0.984 po (24.99 mm), épaisseur 0.139 po (3.53 mm), dehors 1.262 po. Sur un boyau, commence par 1/8 po.

Questions rapides

Je mesure quoi en premier ?

L'épaisseur du rond, la section (CS). Sur un boyau, c'est souvent 1/8 po (0.139 po).

Le dash, c'est la grosseur du boyau ?

Non. Le dash 214, c'est un O-ring : ID 0.984 po, section 0.139 po. C'est pas un boyau de 1/4.
