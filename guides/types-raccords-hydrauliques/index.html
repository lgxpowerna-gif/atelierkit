Types de raccords hydrauliques — guide débutant

RéponseCinq types au comptoir : JIC, ORFS, NPT, BSPP, ORB. Le bout les sépare.

Quel raccord hydraulique type t'as en main? Le nom sur le boyau ne suffit pas. Voici les types qu'on voit tout le temps.

  • JIC 37° : nez pointu, filet droit, siège à 37°.
  • ORFS : face plate, O-ring dans la face.
  • NPT : pipe américain, filet en cône.
  • BSPP : pipe gaz, souvent droit, joint sur la face.
  • ORB / SAE : filet droit, O-ring à la base, pour un port.

Mâle : filet dehors. Femelle : filet dedans. Mesure sur le filet, pas dans le fond. Exemple : 0.562 po.

Questions rapides

Le chiffre sur le boyau suffit ?

Non. 1/2 po peut être le boyau (JIC -8) ou un pipe NPT plus gros. Regarde le bout.

ORFS et JIC, c'est le même type ?

Non. JIC est pointu à 37°. ORFS est plat avec un O-ring dans la face.
